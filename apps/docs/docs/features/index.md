# Features

## Application Tracker

Track every job application across multiple views:

- **Kanban board** with drag-and-drop between stages
- **Table view** with sorting and filtering
- **Calendar view** for interview scheduling
- **Custom stages** — rename, reorder, add, or remove pipeline columns

## Company & Contact CRM

- Company profiles with enrichment data
- Contact management with relationship status tracking
- Link contacts to companies and interviews

## Offer Tracking

- Track compensation packages (base, equity, bonus, benefits)
- Compare multiple offers side-by-side
- Negotiation log

## Resume Builder

Integrated [Reactive Resume](https://rxresu.me) v5 with:

- Multiple resume versions
- Version snapshots linked to applications
- PDF export via headless Chromium

## AI Assistant

Bring your own API key. Supported features:

- **Suitability scoring** — rate how well a job matches your profile
- **Cover letter generation** — tailored to each job description
- **Interview prep** — generate practice questions
- **ATS scoring** — keyword match analysis
- **Resume tailoring** — suggestions based on the JD
- **Ghostwriter** — conversational AI for drafting messages

See [AI Setup](./ai-setup) for configuration.

## Email Integration

Connect Gmail to auto-detect:

- Interview invitations
- Rejections
- Offers
- Follow-up responses

See [Email Integration](./email-integration) for setup.

## Discovery Pipeline

Automated job scraping from:

- Adzuna (REST API)
- LinkedIn, Indeed, Glassdoor (coming soon)

Configure search profiles with keywords, location, and filters. New jobs are scored automatically.

## Data Export

Full JSON and CSV export for:

- Jobs, companies, contacts, and offers
- All data is yours — no lock-in
